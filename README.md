# Innocent WhatsApp Bot

The opponent is anonymous 😳 A multi-feature WhatsApp bot with pairing code.

### Pairing
1. Deploy the bot using buttons below
2. Check logs, you’ll see: `Pairing code: ABCD-EFGH`
3. Open WhatsApp > Settings > Linked Devices > Link a Device > Enter code
