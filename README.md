### 🔗 Pairing Code
[![Get Pairing Code](https://img.shields.io/badge/Pair%20Bot-Get%20Code-brightgreen?style=for-the-badge)](https://github.com/humblemorde-tech/Innocent--morde#pairing-steps)

**Pairing Steps:**
1. Click a deploy button above
2. Go to your app > Logs/Terminal 
3. You’ll see: `Pairing code: ABCD-EFGH`
4. WhatsApp > Settings > Linked Devices > Link a Device > Enter code
